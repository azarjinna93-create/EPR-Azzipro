Admin Panel · Roles

A role is a set of access levels, one per function: No access, View only (lists, documents and prints, without New / Edit / Post / Cancel) or Full. Choosing a role in User setup gives its access to the user; it can then be changed for that one user. An Administrator role has full access to everything, System administration included.
